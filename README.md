# Reinos de Etherial — Remake

Reconstrucción desde cero, mobile-first 9:16, preparada para evolucionar a Telegram Mini App.

## Dirección visual
Fantasía medieval 2.5D, semi-realista animada, con arte original. Lumen debe sentirse como una capital MMORPG monumental: plaza central, fuente/estatua, arquitectura cálida, vegetación, NPCs, profundidad, iluminación y equipo visible.

## Principios
- 720×1280 vertical como referencia de diseño.
- WebGL + Phaser 3.
- Controles táctiles y safe areas.
- HUD interactivo separado del arte del mundo.
- Assets finales prerenderizados/originales; las formas actuales son solo placeholders estructurales.
- Telegram WebApp bootstrap incluido; autenticación segura vendrá después.
- Nada de P2E hasta completar servidor autoritativo y seguridad.

## Primera meta
Recrear Lumen con el nivel visual de la referencia aprobada antes de ampliar mapas, backend o economía.
